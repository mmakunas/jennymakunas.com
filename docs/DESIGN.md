**Repo and hosting.** New public repo `mmakunas/jennymakunas.com` (GitHub Pages free tier requires public; the content is already public). Astro static output, `.github/workflows/pages.yml` deploys `main` with `actions/configure-pages` + `actions/deploy-pages`; with the Actions deploy the custom domain is set in repository Settings → Pages (a `CNAME` file is not the mechanism). **Preview vs production base path (R1-4):** the preview is the project site `https://www.makunas.com/jennymakunas.com/ (the mmakunas user site is served at www.makunas.com; verified 2026-10-31 16:4x)` (a subpath); the production site is served at `/` on the custom domain. The Astro config reads `base` from an environment variable: the Pages workflow builds with `BASE=/jennymakunas.com/` until the custom domain is set, then with `BASE=/`; every internal link and asset path goes through Astro's `base`-aware helpers (no hand-written root-relative paths; a lint step greps the build for `href="/` and `src="/` outside the base). The fidelity pass runs twice: on the preview URL and on a production build (`BASE=/`) served locally by the crew with screenshots in the PR. The switch to `BASE=/` is one commit at the DNS step. Apex redirects to `www` once both are configured on GitHub.

**Content pipeline (crew issue #1).** A Python script `scripts/extract.py` reads the 15 free-URL pages, writes `content/<slug>.md` (front matter: title, order, nav label, canonical path on the custom domain; body: the copy blocks in order) and downloads every image rendition into `public/images/` with `images/manifest.json` mapping Wix URL (with its resize params) → local file. Fonts: record the families and weights Wix loads; self-host only fonts with a license that allows it, otherwise the nearest Google Font with a note in the doc.

**Site (crew issue #2).** Astro layouts: `Base` (header with the Work dropdown of 11 case studies, Thoughts, About, Contact; footer "© 2024 by Jenny Makunas"), `Work` grid, `CaseStudy` with per-page exceptions, three supporting pages. Mobile menu behaviour matches the Wix site. No analytics, no tracking, no Wix. Lighthouse-level checks are not the bar; "as it was" is.

**DNS (Michael, Aside, Sunday).** At Wix → Domains → jennymakunas.com → DNS records: replace the Wix A/CNAME web records with GitHub Pages' four documented apex A records (from docs.github.com, "Managing a custom domain"; Sterling hands Michael the exact list at the session) and `www` CNAME → `mmakunas.github.io`; keep any MX/TXT records (check first whether the domain carries mail; Jenny's mail is on makunas.com, so likely none); also list and keep or remove any CAA and AAAA records (a CAA record that does not allow Let's Encrypt blocks GitHub's certificate; a stray AAAA points IPv6 elsewhere). Leave TTLs as Wix sets them; Sterling confirms propagation with `dig +short` against two public resolvers. Old Wix paths on the custom domain: the Wayback snapshot gives the old URL list; where a new route differs, the crew adds an HTML redirect page at the old path; the free-site `/mysite/...` prefix is not reproduced.
